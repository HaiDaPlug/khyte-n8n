# Learning and Knowledge Capture

9 automation patterns for continuous learning, note-taking, and knowledge management. Focus: actually learn, not just collect.

---

## 1. Reading Queue Management
**Trigger**: Article saved or daily reading time
**Steps**: Capture articles from any source (browser, email, social) → tag by topic and estimated reading time → prioritize by relevance and timeliness → send daily reading suggestion (3-5 articles) → track read vs unread → archive after 60 days unread
**Time Saved**: No overwhelm from 1000+ saved articles | **Variants**: Audio versions, summarization

## 2. Spaced Repetition for Important Concepts
**Trigger**: Scheduled based on forgetting curve
**Steps**: Identify key concepts from notes → create review prompts → schedule reviews at increasing intervals (1 day, 3 days, 7 days, 30 days) → track recall success → adjust intervals based on difficulty
**Time Saved**: Actually remember what you learn | **Variants**: Flashcards, active recall testing

## 3. Article Summarization and Highlights
**Trigger**: Article marked as read or finished
**Steps**: Extract highlights and notes → use AI to summarize key points → tag with relevant topics → link to related notes → store in knowledge base → make searchable for later
**Time Saved**: 10-15 min per article | **Variants**: Tweet threads from highlights, share with network

## 4. Meeting and Call Note Processing
**Trigger**: After meeting or call
**Steps**: Transcribe if recorded → extract action items and key insights → tag with people and projects → link to contact records → identify knowledge worth keeping vs ephemeral → archive structured notes
**Time Saved**: 15-20 min per meeting | **Variants**: Client project notes, learning notes

## 5. Course and Training Completion Tracking
**Trigger**: Enrolled in course
**Steps**: Create course project → break into modules/lessons → schedule study time → track completion → test retention → apply learnings to real projects → celebrate completion
**Time Saved**: Accountability >> abandoned courses | **Variants**: Certification tracking, continuing education credits

## 6. Knowledge Connection Discovery
**Trigger**: New note created
**Steps**: Analyze note content → find related existing notes → suggest bidirectional links → identify themes across notes → surface connections you might have missed → build knowledge graph
**Time Saved**: Insights from connected knowledge | **Variants**: Topic clustering, concept maps

## 7. Weekly Learning Digest
**Trigger**: Sunday evening or Monday morning
**Steps**: Compile week's learning (articles read, notes taken, concepts learned) → identify patterns and themes → surface forgotten notes for review → suggest areas for deeper study → set learning goals for next week
**Time Saved**: 30 min per week | **Variants**: Monthly synthesis, annual review

## 8. Skill Gap Identification
**Trigger**: Monthly or after project reflection
**Steps**: Analyze recent projects and struggles → identify skills you needed but lacked → research learning resources → prioritize based on career goals → create learning plan → track skill development
**Time Saved**: Targeted learning >> random consumption | **Variants**: Industry trend alignment

## 9. Knowledge Sharing and Publishing
**Trigger**: Meaningful insight or pattern identified
**Steps**: Extract shareable insight from notes → develop into shareable format (blog post, LinkedIn post, tweet) → publish → track engagement → link back to original notes → build reputation
**Time Saved**: "Learn in public" benefits | **Variants**: Newsletter, speaking opportunities
