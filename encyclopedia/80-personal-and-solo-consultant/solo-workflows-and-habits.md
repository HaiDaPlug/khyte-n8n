# Solo Workflows and Habits

9 automation patterns for personal productivity, time management, and accountability. Focus: systems that work when it's just you.

---

## 1. Daily Planning and Prioritization
**Trigger**: Every morning at chosen time
**Steps**: Pull open tasks from all sources → identify tasks due today or overdue → score by urgency and importance → suggest top 3-5 priorities → time-block calendar → send daily brief → track completion by end of day
**Time Saved**: 15-20 min per day | **Variants**: Weekly planning, time-of-day preferences

## 2. Time Tracking and Billing Automation
**Trigger**: Calendar event ends or manual time entry
**Steps**: Detect billable meetings/work → extract client and project → log time with description → categorize (billable vs non-billable) → accumulate for invoicing → suggest when to invoice (threshold reached)
**Time Saved**: 30-60 min per week | **Variants**: Automatic time rounding, project budgets

## 3. Weekly Review and Reflection Automation
**Trigger**: Friday afternoon or Sunday evening
**Steps**: Compile week's accomplishments (completed tasks, meetings, revenue) → identify incomplete items → move to next week or archive → calculate hours worked → suggest adjustments for next week → send reflection prompts
**Time Saved**: 30-45 min per week | **Variants**: Monthly reviews, goal tracking

## 4. Admin Task Batching Reminders
**Trigger**: Weekly on designated "admin day"
**Steps**: Create batch of admin tasks (expense reports, invoicing, bookkeeping, filing) → block calendar for batch processing → send reminder with checklist → track completion → reward yourself when done
**Time Saved**: Batching reduces context switching | **Variants**: Monthly batching, task-type specific

## 5. Email Processing and Inbox Zero
**Trigger**: Twice daily (morning and afternoon)
**Steps**: Process inbox in batch → categorize emails (action, waiting, reference, delete) → create tasks from action emails → file reference emails → archive processed → track inbox count → celebrate zero
**Time Saved**: 30-60 min per day | **Variants**: Email templates, smart filters

## 6. Distraction Blocking and Focus Time
**Trigger**: Designated focus time blocks
**Steps**: Block distracting websites and apps → set Do Not Disturb → notify contacts you're unavailable → start timer → track focus session → send break reminders → log productive time
**Time Saved**: Quality of work >> quantity | **Variants**: Pomodoro technique, energy-based scheduling

## 7. End-of-Day Shutdown Ritual
**Trigger**: End of workday (designated time)
**Steps**: Review tasks completed today → move incomplete to tomorrow → clear desktop and close tabs → plan tomorrow's top 3 → log work hours → send "day complete" notification → prevent evening work creep
**Time Saved**: Work-life boundary (mental health) | **Variants**: Weekend shutdown, vacation mode

## 8. Project Milestone Tracking
**Trigger**: New project started or milestone date approaching
**Steps**: Break project into milestones → set deadlines → create tasks for each milestone → send progress reminders → alert on milestone delays → celebrate completions → track project velocity
**Time Saved**: 20-30 min per project | **Variants**: Client milestone sharing, buffer time

## 9. Personal Energy and Capacity Monitoring
**Trigger**: Daily check-in
**Steps**: Log energy level and mood → track capacity (low/medium/high) → suggest task types for current energy (admin when low, creative when high) → identify patterns → adjust schedule to match energy rhythms
**Time Saved**: Work with your rhythms, not against | **Variants**: Health tracking integration

2. **Time Tracking and Billing** (#2) - Don't lose billable hours
3. **Weekly Review** (#3) - Learn and adjust
4. **End-of-Day Shutdown** (#7) - Protect work-life balance
